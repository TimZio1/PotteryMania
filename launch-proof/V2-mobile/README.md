# V2 — Mobile (reality proof)

## Minimum proof

- [ ] **One screen recording** (MP4 or similar) covering **at least one** of: onboarding **OR** product creation **OR** checkout, on a real phone.

## What reviewers must see

- Thumb usage (one-hand plausible).
- No obvious struggle (excessive zoom, fighting the UI).
- No blocked inputs (keyboard covering primary fields without scroll fix).

**Suggested filenames:** `v2-ios-onboarding.mp4`, `v2-android-checkout.mp4`

**Devices (protocol):** ideally both iPhone (Safari) and Android (Chrome); **minimum** for beta gate is **one** device per master checklist.
